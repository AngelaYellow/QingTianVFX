# M2：从两团软光到有层次、会流动的雾

2026-11-16。本轮图外素材已准备；以下节点仍由用户亲手搭建。目标是第一次看到内部明暗和缓慢流动，不把这一版称为风格帧最终还原。

## 先理解这次的结构

一团雾不是一个巨大的不透明圆，而是多片薄雾叠加。每片是带柔边纹理的Quad，宽窄、位置、倾角不同；重叠处更亮，间隙更暗。HLSL只计算每片的位置、尺寸、角度和透明度，粒子的生成、存储与绘制仍全部由VFX Graph完成。

本轮保留两个VisualEffect实例共用一张图，每团32槽，合计64槽。所有粒子一次生成，不反复生灭；以alpha渐隐多余雾片。四锚点可见数分别是每团24/16/20/12，合计48/32/40/24。过渡时有正在淡入淡出的片数，不能把Float目标数当整数aliveParticleCount。

## 1. 扩成固定粒子池

先退出Unity Play，打开M2_Mist图。在Spawn的Single Burst把Count从1改成32，Delay保持0；Initialize的Capacity也改成32。

Initialize仍是World、Manual Bounds中心(0,0,0)、Size(20,12,4)；原Set Size=1保留。

**为什么：** Count是本次出生数量，Capacity是最大存储槽数。两个实例各32，总64。稍后由HLSL决定哪些片透明，不用每到一章就销毁和重生。现在所有片仍重叠在一起，先完成后面步骤再Play。

## 2. 添加5个Float属性

Blackboard左上`+ → Property → Float`，逐个命名并勾选Exposed。已有的五个通用属性都保留。

| 名字（必须完全一致） | 默认值 | 含义 |
|---|---:|---|
| MistSizeWorld | 4 | 单雾片长轴的基准世界尺寸；桥把MistSize×画幅世界宽度后写入 |
| MistTargetCount | 48 | 两团合计目标数；HLSL内部平分，不能手工再除2 |
| MistOpacity | 0.14 | 每片薄雾的透明度，低alpha叠加出层次 |
| FlowPhase | 0 | 从歌曲开始累计的流动相位，暂停冻结、seek可重现 |
| MistPhaseOffset | 0 | A/B固定错相，运行时桥分别写0和2.17，避免两团内部运动完全相同 |

**为什么：** Exposed让桥能按名字写值。默认值只是未运行时的备用值，Play后来自歌曲参数。MistSizeWorld是派生端口，原合同MistSize仍保持画宽比例；MistTargetCount/MistOpacity/FlowPhase已有桥输出，无需另写时间线。

## 3. 暂停旧的统一位置、尺寸和alpha设置

在Update里取消旧`Set Position`、`Set Scale.XYZ`、`Set Alpha`三个块左上角的勾。保留原块与连线，方便回退。保留启用的`Set Color`及`LightColor × LightGain → Color`连线。

**为什么：** 旧块让所有粒子取同一个位置和尺寸，新HLSL要给每片不同的值。Update里的块按顺序执行，同一个属性被后面的块重写，就会丢掉前面的结果。颜色与音乐呼吸仍沿用原来的乘法，避免重复叠加节拍。

## 4. 在Update中加入Custom HLSL

鼠标放在Update框内的空白处按Space，搜索`Custom HLSL`，添加`HLSL > Custom HLSL`块。不要在画布空白处添加同名Operator。

选中这个新块的标题，在右侧Inspector找`Shader File`，点右边小圆圈搜索并选择`MistMotion`（文件在`Assets/QingTian/Shaders/M2/MistMotion.hlsl`）。Inspector锁定时先解除锁定。回到块内，Available Function选`QingTianMist`。

**为什么：** Custom HLSL Block可以写粒子属性。一个经过检查的函数承担每片雾的分布与流动，避免新手图里堆大量三角函数和随机节点。程序仍运行在VFX Graph的GPU更新阶段，没有换成C#粒子。

**应看到：** 出现Light Center World、Light Scale World等8个输入（Unity可能自动把名字加空格）。如果仍是Offset/Speed Factor，说明外部文件尚未选中。`attributes`是系统提供的粒子属性，不需要你接一根线。

## 5. 把8个输入接好

把下表Blackboard属性拖到画布，从属性节点右侧端口连到Custom HLSL左侧同名端口。Vector3接整组圆点，不拆XYZ。

| Blackboard输出 | Custom HLSL输入 | 控制内容 |
|---|---|---|
| LightCenterWorld | Light Center World | 这团雾的中心，继续服从四章位置 |
| LightScaleWorld | Light Scale World | 雾片中心分布的横纵范围 |
| MistSizeWorld | Mist Size World | 每片本身的长轴尺寸 |
| MistTargetCount | Mist Target Count | 透明度加权的可见目标数 |
| MistOpacity | Mist Opacity | 单片透明度 |
| FlowPhase | Flow Phase | 内部运动进度 |
| MistPhaseOffset | Mist Phase Offset | A/B布局差异 |
| MasterGain | Master Gain | 片头淡入、片尾淡出 |

**为什么：** LightScale描述整团空间分布，MistSize描述单片大小，两者职责不同。FlowPhase来自歌曲积分，不能换成Total Time；否则音乐暂停时雾会继续走，seek也难以重现。旧SetColor仍独立负责颜色，结构保持可读。

## 6. 换成内部有浓淡的纹理

在Output Particle Unlit Quad（Render Quad）中，把Main Texture从SoftDisc换成`MistWisp`，位于`Assets/QingTian/Textures/M2`。Blend Mode保持Additive，Alpha Clipping不勾选；Initialize Set Size仍为1。

**为什么：** SoftDisc是规则的径向圆，新纹理是非均匀的薄雾透明度，边缘完全透明。HLSL把每片拉成长条并轻微倾斜，移动的透明度花纹叠加出内部明暗。Additive适合黑幕发光雾，但它不是会挡住后景的真实体积烟；现阶段不加真体积光/DOF。

导入已由助手设置：256×256，白RGB/透明度形状，线性、Uncompressed、Clamp、Trilinear、Mipmaps。Mipmaps让缩小时的细纹更稳定；它不是景深效果。

## 7. 保存并看第一次流动

Ctrl+S保存图，点击Unity Play。开头8秒有渐入，先等10秒。F回调试面板，点上方`锚点 C1`定位56.80秒（这会暂停），再点面板`播放`，F回纯画面，连续看10–20秒。

**应看到：** 两处光变成多片叠出的柔雾，有浓淡而非均匀填色，局部缓慢移动和交叠，颜色/整体亮度继续随音乐。薄雾可能比原单个软圆暗一些；先检查纹理和流动，再统一校准亮度，不能直接把每片alpha改成1。

暂停时局部应停止，继续播放再流动。只看锚点暂停截图无法验证流动。预览窗口未进入歌曲Play时FlowPhase默认0也会静止，这是正常的。

## 8. 比较两章并反馈

F返回面板，分别定位C1和C2，观察整体中心与章间分离方向；再从70秒连续播放到100秒，看整体移动、片内流动和呼吸是否协调。先把参考叠图透明度设0，看纯粒子，再提高透明度比较位置/范围。

本轮反馈：一张纯雾画面、一张Update及接线截图，并描述“能否看出慢流动、是否过亮/过暗或碎成条”。先确认结构通了，再做四锚点的尺寸和浓淡校准。

## 常见现象与定位

| 现象 | 优先检查 |
|---|---|
| 仍是两个规则圆/32片完全重叠 | 旧Set Position/Scale是否停用；新HLSL块是否在Update且启用 |
| 画面突然很白 | 旧Set Alpha仍在覆盖；MistOpacity是否误接成MasterGain或默认1 |
| 有雾但不流动 | FlowPhase是否Exposed并连接；歌曲是否被锚点按钮暂停 |
| 图出现Offset与Speed Factor | 还在用Custom HLSL默认示例，需在Inspector选Shader File |
| 雾消失 | 查看红色编译错误；Main Texture选对；8条线完整；FlowPhase=0本身不会导致消失 |
| 片尾不灭 | MasterGain没有连到HLSL输入 |

## 实现选择和验证边界

- HLSL里每相邻两片使用相反位置和180度镜像旋转；同alpha权重使理论亮度质心稳定。形态仍有自然不规则，不能把粒子位置质心测试冒充Bloom后画面像素中心测量。
- 尺寸：MistSize×画宽换为世界长轴，再给每片0.72–1.0倍；短轴约长轴的0.26–0.34倍。LightScaleWorld当前改为粒子中心的分布包络依据，其可见轮廓还受纹理、片尺寸与叠加影响，须用实际图校准。这是初版艺术选择，不是从图测出的物理模型。
- FlowPhase是FlowSpeed的积分，本轮乘无量纲系数作曲线路径的相位；不再把计划中的W/s解释成每片真实位移速度。尚未改动原合同/预设，最终速度靠实际歌曲观看确认。
- 未使用GPU随机逐帧重抽、速度积分、粒子寿命、GPU事件、HDRP体积或平台专用指令。仅基础Quad与数学运算；iPhone/Metal仍待构建和真机验证。
- 实际GPU Compute测试直接include同一个HLSL，不创建VFX图，检查数量分摊、成对中心、180度单位、seek/暂停一致、连续性和有限范围。它验证计算公式，不替代用户图的整条VFX编译、渲染、视觉与性能验收。
- 官方依据：[Custom HLSL Block](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.3/manual/Block-CustomHLSL.html)、[HLSL文件与类型](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.3/manual/CustomHLSL-Common.html)、[粒子属性与角度单位](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.3/manual/Reference-Attributes.html)。已同时核对本机17.3包源码：Shader File首次从Inspector选择，VFX angle用度而非弧度。
