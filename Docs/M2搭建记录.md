### 上述设置的原理

四个Context分工：Spawn决定何时申请生成多少粒子；Initialize在每个新粒子出生时设置初始属性；Update持续更新已有粒子；Output决定如何绘制。音乐位置需要在后续Update持续写入，放在Initialize只能取得出生时的位置。

Single Burst在触发时一次性提出生成请求。Count=1是本次生成数量；Delay=0表示不加该块的额外等待时间，不意味着音频与GPU在同一微秒开始。用同一个粒子跟随位置，可以先排除大量粒子生成/消失对验证的干扰。Count=1为管道验证临时值。

Capacity是系统可容纳粒子的容量，不会单独触发生成；Count是生成请求量。此处两者都设1使验证目标明确，扩展雾时再回到总容量64。容量不是GPU字节数，实际缓冲区分配还受引擎对齐等影响。

Local相对于VFX对象的坐标系，World相对于场景世界坐标。桥把参考图0–1坐标转成世界位置，所以图采用World。以C1为例，LightCenterA约(0.2603,0.3306)，换算后为(-4.2621,1.6940,0)。原图y向下，世界画面y向上，翻转已由桥处理。

Bounds是供可见性/剔除判断使用的包围盒，不是发射形状，也不改变粒子大小。Recorded需要录制出合适范围；当前已知完整移动画幅，因此先用Manual。当前正交相机Size=5代表可见高度的一半，画幅高10、宽10×16/9≈17.78。中心(0,0,0)、Size(20,12,4)为这个画幅保留余量；VFX对象当前变换为单位变换，盒子覆盖x=-10…10、y=-6…6、z=-2…2。它是当前单点验证的实用范围，不是固定通用值；后续雾片更大或镜头变化要复核。Padding=0因为已在Size留边；Bounds过小会导致错误剔除，过大则降低剔除效率。

## 已完成的3步骤：A光颜色

1. 在Edit Mode打开M2_Mist。Blackboard `+ > Property > Color`，命名`LightColorA`，勾Exposed，默认白色RGBA=(1,1,1,1)。Color是颜色类型，RGB为色彩，A为透明度；白色作为未播放时的中性初值。正式颜色由参数桥覆盖，不手填每章颜色。已有合同含线性颜色，图内无需再次做Gamma/Linear转换。
2. Update Particle内部添加普通`Set Color`（不是Random或Over Life）。把LightColorA拖出Blackboard，右侧颜色输出连接Set Color左侧Color输入，保留原Set Position连线。这样位置和颜色每次模拟都更新。Set Color只写RGB，当前透明度仍由默认粒子alpha及SoftDisc透明通道决定。
3. 将Initialize中已有Set Size从0.3改为1，保存，Play观察；1世界单位对应当前画幅高度的10%，仅放大以便检查色彩，不是最终雾尺度。Play默认纯画面；F回面板使用锚点按钮看章节差异。预期A光由白色变成淡紫/粉紫，C1偏淡紫、C2更粉，暂时仍只有一个软圆点。等节点连线截图和颜色反馈后再继续。

用户已提供[C1淡紫](Evidence/M2/user_04_colored_A_C1.png)、[C2粉紫](Evidence/M2/user_05_colored_A_C2.png)，保存图也确认Color属性已暴露并连接，Size=1。

## 当前指导的8步：共用图生成粉青双光

助手已准备场景中的VFX_LightA/B，二者引用同一份M2_Mist.vfx，各自桥分别读取合同A/B数据。用户只改一份图。图外换算已就绪，尚未验证用户改名后的双光输出。[准备回读](Evidence/M2/two-light-instances-prepared.json)。

共用端口是原合同的适配输出，不修改原52参数名称或预设：

| 图端口 | 类型 | 默认值 | 运行时来源/用途 |
|---|---|---|---|
| LightCenterWorld | Vector3 | (0,0,0) | 本实例LightCenterA或B投影后的世界位置 |
| LightColor | Color | 白，alpha1 | 本实例LightColorA或B，已是线性颜色 |
| LightScaleWorld | Vector3 | (1,1,1) | 本实例LightScaleA或B按画宽/画高换算的完整Quad尺寸，z=1 |
| LightGain | Float | 1 | 本实例LightGainA或B；已有RMS/节拍平滑微扰 |
| MasterGain | Float | 1 | 原合同片头/片尾渐隐，0–1 |

1. **改名为共用位置/颜色。** 退出Play，在Blackboard选LightCenterAWorld按F2改为LightCenterWorld；LightColorA改为LightColor。保留Exposed，原有连线保持。去掉A并非丢掉A/B数据，而是让两实例用同样的插口接收各自数据；无需复制整套节点。
2. **添加3个输入。** `+ > Property > Vector3`创建LightScaleWorld，默认(1,1,1)；再创建Float LightGain=1、Float MasterGain=1，全部Exposed。Scale分横纵比例，Gain是亮度倍数，MasterGain控制全曲渐入/渐出；默认1是中性值。
3. **接尺寸。** Update内部添加普通Set Scale，Channels=XYZ（标题可显示Set Scale.XYZ）。LightScaleWorld拖到画布，整组Vector3输出接Scale输入。Initialize的Set Size保留1，因此最终宽高=Size1×Scale；不要把Scalar Size改成4.62，也不拆X/Y/Z接线。C1 A预期Quad约4.6222×2.0单位；这是初版完整面片尺度，软纹理可见边界会更小。
4. **接轻呼吸。** 画布空白处按Space添加Math/Arithmetic/Multiply运算节点，将LightColor输出接第1输入，LightGain输出接第2输入，Multiply输出连接Update Set Color的Color输入，替换原直接颜色线。Gain=1颜色不变，略大于1稍亮；它已包含音量/节拍，不再额外乘一次BeatPulse。Multiply在画布外部，不是添加到Update里的Multiply Color块。
5. **接全曲渐隐。** Update内部添加普通Set Alpha；MasterGain拖到画布，输出接Alpha。Alpha是粒子整体不透明度，与SoftDisc自身边缘透明度相乘。片头从0渐亮、片尾渐灭；不要接到Set Alive，否则会提前杀死固定粒子。
6. **选择发光叠加并核对预算。** Output Particle Unlit Quad的Blend Mode由Alpha改为Additive；Main Texture仍SoftDisc。两光重叠会叠加亮度，适合当前光场初形。Spawn Single Burst Count1/Delay0、Initialize Capacity1/Size1/World均保持，一份图由两实例运行，合计2粒子。后续雾的透明混合会单独校准，不等同于今后全层都用Additive。
7. **看双光。** Ctrl+S，Play，在纯画面观察。开头MasterGain渐入，几秒内应出现粉紫和青色两团椭圆软光。Hierarchy已由助手准备VFX_LightA/B，无需另拖图或复制对象。若只看到一个，优先检查第1步确实去掉A、且属性均Exposed；未改名期间两实例会读取旧A端口而重叠。
8. **核对章节和呼吸。** F回面板，依次点上方锚点C1–C4：C1相对靠近；C2拉远并呈左下/右上；C3比C2靠近；C4A退到左下、B在右侧，A更弱。随后拖至70秒点面板播放，看到100秒，观察连续位置/大小和轻微亮度呼吸。锚点按钮暂停歌曲，暂停时不应继续呼吸；图可静止但实际全曲播放时应动态。发整体节点图及C1/C2画面反馈。

这一步只建立两处光的范围/颜色/呼吸，不声称已是完整雾。后续用稳定分布、多片软纹理和HLSL形变增加层次；每实例最多32槽，总64，不能每团64。尺寸合同未定义sigma或等亮边界，本轮完整Quad宽高解释是初值选择，最终需与参考复测。

对应关系：`LightCenterWorld → Set Position`，`LightScaleWorld → Set Scale.XYZ`，`LightColor × LightGain → Set Color`，`MasterGain → Set Alpha`，四个Set块均在Update。

依据：[VisualEffect实例与属性覆盖](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.3/manual/VisualEffectComponent.html)、[Set Attribute](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.3/manual/Block-SetAttribute.html)、[Multiply](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.3/manual/Operator-Multiply.html)。节点字段已从本机17.3官方包核实。
