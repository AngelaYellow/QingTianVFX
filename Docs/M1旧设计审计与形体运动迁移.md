# M1旧设计审计与形体运动迁移

2026-11-16。最高原则见DEVELOPMENT第0节。本轮按用户要求检查并列出改动，不改写ScoreModel、播放器、参数JSON或用户VFX图。旧实现保留为回归基线，不再代表M2的新视觉设计。

## 精确定位旧假设

| 源码位置（本轮检查时） | 当前行为与问题 | 应改内容 |
|---|---|---|
| `ScoreModel.cs:123–130`，Smooth/Span | 第一锚点前a=b=0，末锚点后a=b=3；中间是端点导数为0的五次插值。中心与轮廓基准长时间固定，锚点又易成为动作停靠点 | 动作范围覆盖0–269.747秒，包含进入C1之前和离开C4之后的路径；使用确认剧本组织形体轨迹，不再把四预设插值当成总运动导演 |
| `ScoreModel.cs:177,193,195`，AnchorFreedom/exact | 距锚点0.85秒的Smooth权重同时压中快层；精确时刻所有Final强制回预设 | 从新形体动作链中撤掉统一压零门。锚点约束位置/形态/视觉关系，保留经过它的速度、方向和后续去向；必要的构图修正不能把所有动作自由度一同消掉 |
| `ScoreModel.cs:187–191` | 尺度句变化仅约±1.25%，亮度RMS约±8%加6%Beat；低频主要改丝宽/雨速，高频改NoiseAmp。没有大形体旋转/弯曲/推进的输出 | 音乐调节主体推进速度、伸展程度、弯曲、卷动、分离/靠近和冲击；保留音频平滑与限幅，但响应幅度按Web确认结果定标，不简单把旧系数乘10 |
| `ScoreModel.cs:94–95,205`，FlowPhase | 积分的是慢层FlowSpeed，RMS/低频/段落能量不改变其速度；形式上在动，不保证大形体有动感 | 保留可seek的时间基础；新增形体动作相位/速度来源。若实时积分有历史，明确状态保存、重播重置和seek重建策略，不能声称与无历史求值天然等价 |
| `ScoreModel.cs:144–153`，PhraseEnvelope | 每句只以20%起/35%落和成形权重表示，句间为0 | 句包络可作为输入，但新语义是“收拢→牵引/转向→展开/卷回”等动作阶段；句间仍有基础形体流动，不能把包络0当作运动0 |
| `ScoreModel.cs:156–165`，PulseAt | 40ms预起/180ms释放的标量脉冲 | 保留既有节拍时间，派生形体冲击及空间传播/尾部滞后；旧BeatPulse可以作为输入，不能将它等同于最终全局位移，也不能所有区域同相缩放 |
| `ScoreModel.cs:178`，MasterGain | 开头8秒透明度渐入、末段渐出 | 可以保留渐入/渐出，但形体从t=0就计算运动，不能等8秒后才启动，也不能淡出时锁C4。t=0/终点数学瞬间黑场和用户手动暂停是允许的边界 |
| `VfxParameterBridge.cs:40–51,93` | 当前通用LightCenter/Scale来自旧Final，新增MistSizeWorld/错相，但没有形体动作帧 | 新桥明确区分参考构图数据、形体动作输出、原始音乐信号；在GPU中让各层采样共同形体场，C#不逐粒子改位置 |
| `MistMotion.hlsl` | 雾片围绕LightCenter成对运动，强制整体中心稳定；能产生局部游移但没有整团推进/大尺度演变 | 降为旧实验。新模块先定义整团的脊线/空间形变与整体运动，再把粒子分布在形体上；局部噪声最后加，不能用局部运动代替主体运动 |

这里不是说数学插值本身不能用。轨迹、形变场或控制点可以插值；被撤回的是“把四张静态预设混合起来，再加一点扰动就等于整曲视觉”的设计。

## 参数合同怎么迁移

当前JSON是1.2版、52名/82分量，本轮原样保留。新的动作合同应独立版本化，并带已确认Web版本信息。

| 参数族 | 保留什么 | 新含义或补充 |
|---|---|---|
| LightCenterA/B、LightScaleA/B、LightColorA/B、Gap相关 | 四关键瞬间的测量/艺术预设和原始单位 | 是锚点约束或外观目标，不能让其两点插值决定全部运动；范围和最终输出需要结合完整动作审查 |
| FlowA0–A3、FlowB0–B3 | 可复用的空间控制点数据 | 作为形体脊线或方向信息的候选输入；需有路径随时间的演变、材料在路径上的输运和尾部延迟 |
| FlowSpeed、NoiseAmp/Frequency | 基础速度/局部细节概念 | 区分形体推进、材料沿形体流动、局部扰动三种速度；Noise不能作为宏观运动替代品 |
| FlowerForm/Break、句包络 | 成形语义、原始句时刻 | 改为有动作阶段的收聚、旋转、展开、散出；花不是每句淡入的一张贴图 |
| TargetCount、MistOpacity、MasterGain | 资源预算、层密度、全曲淡入淡出 | 不作为C1切C2的主要变形手段；同一形体的材料应持续移动，目标数量调整只服务层次和预算 |
| Rms01/Low01/High01/Onset01/BeatPulse | 实测输入与既定节拍时刻 | 进入形体速度/幅度/冲击，原始信号不在锚点伪造或置零 |
| 新增形体动作输出 | 当前不存在，不能假装已能绑定 | 拟含BodyPhase、形体中心/朝向、伸展、弯曲/扭转、分离关系、推进/冲击及尾部延迟。具体字段/范围必须由确认剧本和所选GPU表达反推 |

**不要追求所有新动态自由度在四锚点都严格等于0。** 应约束构图和形态，而不是速度、相位、冲击历史。可让形体位置经过目标同时仍有速度；若某个局部转向点瞬时速度为0，也不能误判整幅停住。

## 保持什么不动

- `SongClock`的DSP时基、播放排程、Pause/Play/Seek/Stop/Ended与269.747秒终点。
- `QingTianPlayer`音频播放、采样/归一化、跳转与重播入口，以及M1原场景和叠图工具。
- 章节/歌词句时间标签、68 BPM既有节拍时刻、4个锚点时间。
- M1现有测试和证据作为历史基线；不改断言来掩盖失败，不把旧测试通过写成新形体方案已经通过。

## 测试迁移方式

| 现有测试 | 处理 |
|---|---|
| ScheduledClockStartsAtZeroAndClampsAtSongEnd / PauseResumeHasNoWallTimeDrift / SeekWorksPlayingPausedAndAtEndAndReplayResets | 原样保留 |
| 真实AudioSource PlayMode时钟/暂停/seek/重播，Overlay测试 | 原样保留 |
| 章句推进、数值有限/范围、信号清洗、68 BPM点列 | 原样保留；未来新动作字段增加自己的范围断言 |
| EveryAnchorExactlyEqualsPresetDespiteAudioExtreme | 继续验证**旧M1参数通道**。新动作通道另测形态锚点误差和穿行，不复用“所有Mid/Fast严格为0”断言 |
| AllMusicalBoundariesAreContinuous | 保留数值连续；新增动作路径/轮廓连续与速度连续检查。连续不等于有动感 |
| RandomSeekingReturnsSameParametersAndFlowPhase | M1仍要求确定性。新系统先选seek策略：解析/缓存重建，或状态模拟的检查点+固定步重演；同一录制输入重建要可验证。不能既采用实时历史积分，又承诺直接跳转自然逐像素一致 |
| MistMotionTests的成对中心/180度镜像 | 仅对应旧雾算法；新形体不应受“中心恒定”的全局约束。新测试验证材料跟随形体、整体动作与渲染边界 |

新增验收：前奏和尾奏有主体运动；四锚点前后连续穿行且没有冻结平台；相同声学输入下主副歌动作幅度/速度符合确认剧本；重音有空间前后关系；暂停完全冻结、重播正确重置、seek无爆跳；隐藏星尘后仍有大形体动感；覆盖整曲的中间帧构图抽检。数值阈值以确认Web片段定标，不凭空给“好看”打分。

## 落地顺序与版本边界

1. 冻结确认后的Web提交/源码哈希、段落动作表、指定参考片段。正在修改的工作树不是发布基线。
2. 增加形体动作帧与M2专用求值/桥，复用SongClock和音乐信号；先用低成本形体轮廓验证大动作，保持M1场景走旧通道。
3. 用户手搭VFX图接入形体场，确认整体动作后再加薄雾材质/细节。先通动作再通外观，防止密集细点掩盖主体静止。
4. 四锚点连同前后窗口一起验收。通过后再考虑迁移旧ScoreModel视觉部分、更新合同与对应测试；不先删除历史基线。

这是一份迁移清单，**尚未实施新运行时动作导演，也未改动旧运行时**。本轮CLI报告只证明基线没有退化。
