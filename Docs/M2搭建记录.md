# M2 · 柔光雾与两处光

开发上下文以[DEVELOPMENT.md](../DEVELOPMENT.md)为准。本页记录共同搭图过程；每次只推进一小步，截图确认后才继续。

## 分层与本轮范围

1. 柔光雾和两处光：当前M2，先定位置/大小/颜色和呼吸。
2. 光纤丝带：确定主流向和轮廓。
3. 星尘与光斑：分别增加细小亮点与近景柔斑。
4. 花形聚散：跟歌词句形成局部可辨结构。
5. 斜雨与共享黑隙：黑隙是已有层的遮罩/避让，不是黑粒子。
6. 整体虚实与Bloom：逐层已有最低限度软硬处理，最后统一。

M2每个关键帧只评价两光关系，不要求雾承担细丝、星点或花的形状。总容量64，可见24–48；A/B不是两套独立64预算。第一关仅1粒子。

## 当前已完成的图外准备

- 场景`Assets/QingTian/Scenes/M2_MistAndLights.unity`，M1保持原文件。
- Camera：正交Size=5，Position=(0,0,-10)，视平面z=0，16:9，RT=1280×720 RGBA16F+深度，单采样，黑背景。
- Bloom：独立Volume，Intensity=.35、Threshold=1、Scatter=.65、High Quality Filtering=false。覆盖关闭管线模板继承的Neutral色调映射和暗角。未做粒子视觉效果验收。
- `VFX_Mist`对象已有VisualEffect和VfxParameterBridge，位置/旋转0、缩放1；Graph暂空。
- `LightCenterAWorld/BWorld`为桥派生Vector3，原合同`LightCenterA/B`仍为0–1 Vector2；y在桥中翻转。图使用World空间，避免再做一次坐标转换。
- M2复用播放器的所有章句/节拍/音量逻辑，证据单独输出`Docs/Evidence/M2`。

## 当前给用户的一小步：创建图资产

1. 确认Unity顶部Play按钮未处于播放状态，在Project窗口进入`Assets > QingTian > VFX`。
2. 空白处右键，选择`Create > Visual Effects > Visual Effect Graph`；模板窗口选`Minimal System`，点击`Create`。
3. 命名为`M2_Mist`并保存到当前VFX目录，双击打开。

预期：打开VFX Graph窗口，模板中有Spawn、Initialize、Update、Output四个已连好的Context。当前不调整块/值/连线，不添加第二套系统，不开始搭雾。把整个图窗口截图给助手，下一小步按实际界面配置单粒子。官方入口：[Creating Visual Effect Graphs](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.3/manual/GettingStarted.html)；模板名称也已从本机17.3包`01_Minimal_System.vfx.meta`核实。
